# 🎰 SuperDice Casino Bot
Telegram-бот для азартных игр с системой рефералов, пополнением через Telegram Stars и криптовалюту (TON), а также админ-панелью для управления настройками и статистикой.

📌 О проекте
SuperDice – это полноценный игровой бот для Telegram, который предлагает пользователям несколько мини-игр (кости, дартс, баскетбол, футбол, боулинг, слот-машина). Игровой процесс построен на случайных событиях, а баланс ведётся во внутренней валюте – звёздах. Проект включает:

Автоматическую регистрацию пользователей

Реферальную программу с начислением бонусов

Пополнение баланса через Telegram Stars и CryptoBot (TON)

Вывод средств с модерацией администраторами

Административную панель для настройки игр, просмотра статистики и управления пользователями

Бот написан на Python с использованием библиотеки aiogram 3.x, асинхронной работы с базой данных (SQLite через SQLAlchemy) и интеграции с платежными сервисами.

📦 Установка и запуск

1. Клонирование репозитория

```bash
git clone https://github.com/RusGheast/minigames-stars-casino-bot.git
```
```bash
cd minigames-stars-casino-bot
```

3. Установка зависимостей

```bash
pip install aiogram sqlalchemy aiosqlite dotenv
```

3. Настройка переменных окружения

Создайте файл .env в корне проекта и заполните его по образцу (см. раздел Настройка переменных).

4. Инициализация базы данных

```bash
python migration.py   # добавит необходимые колонки и создаст таблицы
```

5. Запуск бота

```bash
python main.py
```

🔐 Настройка переменных окружения

Файл .env должен содержать следующие параметры:

Переменная	Описание

BOT_TOKEN	Токен вашего бота (получить у @BotFather)

PAYMENT_PROVIDER_TOKEN	Токен провайдера для Telegram Stars (оставить пустым, если не используется)

CRYPTOBOT_TOKEN	Токен CryptoBot API (получить в @CryptoBot)

ADMIN_IDS	Список ID администраторов через запятую (например, 123456789,987654321)

HISTORY_CHAT_ID	ID чата, куда отправлять логи игр

WITHDRAWAL_CHAT_ID	ID чата, куда отправлять заявки на вывод

Содержание .env:
```env
BOT_TOKEN1 = ''
PAYMENT_PROVIDER_TOKEN1 = ''
CRYPTOBOT_TOKEN1 = ''
HISTORY_CHAT_ID1 =
WITHDRAWAL_CHAT_ID1 =
```

🖥 Административные команды (в личных сообщениях боту)

Доступны только для пользователей из списка ADMIN_IDS:

/admin – открыть панель администратора

/settings – показать текущие настройки всех игр

/games_history – вывести последние 20 игр (только для просмотра)

Изменение параметров через прямые команды (например, /chance_dice 0.5) – подробнее описано в админ-панели.
